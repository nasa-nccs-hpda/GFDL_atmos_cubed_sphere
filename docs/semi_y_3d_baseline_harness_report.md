# semi_y_3d Baseline Harness Report

Date: 2026-06-16

## Summary

Created a standalone Fortran baseline harness for:

```text
src/atmos_spectral/model/fv_advection.F90
fv_advection_mod::semi_y_3d
```

Harness location:

```text
tests/fortran_baseline/semi_y_3d/
```

## Direct Callability

`semi_y_3d` is not directly callable from an external test program.

Reason:

- `fv_advection_mod` has `private` as the default module visibility.
- Only `fv_advection_init`, `fv_advection_end`, and `a_grid_horiz_advection`
  are public.
- `semi_y_3d` is an internal private module procedure.

## Non-Invasive Approach Used

The harness uses a test-only module in:

```text
tests/fortran_baseline/semi_y_3d/test_semi_y_3d.F90
```

That module contains:

- a minimal initializer for the state used by `semi_y_3d`;
- a copy of the original local `semi_y_3d` routine body;
- no FMS, MPP, domain, halo, or production-source dependencies.

Production source was not modified.

## Synthetic Fixture

The fixture uses:

```text
nx = 8
js = 2
je = 6
nz = 3
qx_jlo = 0
qx_jhi = 8
dt = 37.5
```

The generated fields include:

- mixed positive and negative `va`;
- exact zero `va` values to exercise the `>= 0.0` branch;
- nonuniform `dyy`;
- smooth but nontrivial `qx`.
